# Website brand fonts

Bundled on 2026-09-27 from the official [Google Fonts repository](https://github.com/google/fonts): `ofl/fraunces` and `ofl/plusjakartasans`. Original variable TTF files are renamed without axis suffixes; font data is unchanged. The corresponding SIL Open Font Licenses are included here.

Both Next.js routers share `src/lib/brand-fonts.ts` so builds do not fetch Google Fonts. These are website fonts; the certificate package retains its own Cormorant Garamond and Instrument Sans assets.
